# Espejo celular -> Smart TV

- `sender`: app del celular (captura pantalla y audio).
- `receiver`: app de la TV (se instala con Downloader).

Los APK se compilan solos con GitHub Actions y quedan en Releases:

- https://github.com/TU_USUARIO/TU_REPO/releases/download/latest/receiver.apk
- https://github.com/TU_USUARIO/TU_REPO/releases/download/latest/sender.apk
